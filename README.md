# flights_analysis
Анализ авиаперевозок
## О проекте
Анализ данных о внутренних авиарейсах США (25 200 рейсов, 20 аэропортов)
## Данные
- Источник Kaggle (Flight Cancellation Dataset).
- Объем: 25 200 строк, 15 колонок.
- Период: 2018-2019 гг.

## Ключевые выводы
1. **Процент отмен:** 2.02% всех рейсов были отменены (около 509 рейсов).
2. **Самые проблемные авиакомпании по отменам:** Southwest Airlines (74), Frontier Airlines (70), United Airlines (67). Рекомендуется провести аудит причин отмен у этих перевозчиков.
3. **Самые непунктуальные авиакомпании:** Southwest Airlines (12.78 мин средней задержки), United Airlines (12.75), Delta Air Lines (12.74). Задержки негативно влияют на лояльность пассажиров.
4. **Самая загруженная авиакомпания:** United Airlines (3131 рейс). Высокая загрузка не должна идти в ущерб надежности.
5. **Очистка данных:** названия авиакомпаний были приведены к единому регистру через `.str.lower().str.strip()`, чтобы избежать дублей (например, `ALASKA AIRLINES` и `Alaska Airlines`).
6. **Техническая особенность:** отмененные рейсы не имеют задержки вылета (они не вылетели). Это ограничение нужно учитывать при анализе.
